# قَصّة — خطة تحسين تجربة صانع المحتوى

تاريخ التنفيذ: 2026-10-29

## نطاق التنفيذ ومعيار الاكتمال

1. إدارة المشاريع: اسم ظاهر مستقل عن معرّف المجلد؛ إعادة تسمية قابلة للتراجع؛ حذف إلى سلة محلية واسترجاع بدون الكتابة فوق مشروع آخر؛ منع الحذف أثناء العمل على المشروع.
2. الرئيسية: بطاقات وأسماء واضحة، بحث وترتيب، واجهة عربية متجاوبة، حالات اتصال وانتظار وأخطاء، حوارات تدعم لوحة المفاتيح، سلة محذوفات.
3. أدوات AI: إتاحة إعادة التسمية والحذف والاستعادة عبر MCP باستخدام نفس API الذي تستخدمه الواجهة.
4. دراسة مرجعية باستخدام REA إن توفر محليًا، مع فصل الدليل المباشر عن المقترحات. اختيار تحسينات سير العمل بناءً على البنية الموجودة.
5. مراجعة التكامل: اختبارات آلية، TypeScript، بناء الواجهة، وتجربة عملية على مشروع اختبار معزول. لا تعديل لمحتوى مشاريع المستخدم أثناء الاختبار.
6. بعد طلب المتابعة: نقاط رجوع مسماة محفوظة على القرص، استرجاع مع نسخة أمان تلقائية وحماية من تعارض التعديلات، وواجهة داخل المحرر وأدوات MCP.
7. فحص جاهزية التصدير وتثبيت حالة المشروع عند طلب التصدير؛ بيان النسخة في النتيجة واستخدام اسم خرج مستقل لكل تصدير افتراضي.

## حدود الوعد

هدف «أفضل أداة لكل صانع محتوى» اتجاه للمنتج، وليس ادعاء بأن هذه الدفعة تعادل جميع إمكانات CapCut أو DaVinci Resolve. أي ميزة غير منفذة أو غير مختبرة ستذكر صراحة في تقرير التسليم. لا تضاف واجهات لميزات وهمية، ولا ينسخ كود التطبيقات المرجعية أو أصولها.

## خط الأساس

73 اختبارًا نجحت قبل التعديلات. التشغيل داخل sandbox واجه EPERM من realpath؛ أعيد التشغيل خارجه بنجاح.

## تحقق مرحلي

- 106 اختبارات نجحت بعد إدارة المشاريع واختيار جزء المصدر، مع نجاح TypeScript وبناء الإنتاج.
- جُرّبت من الواجهة دورة إنشاء مشروع عربي → إعادة تسمية → حذف إلى السلة → استعادة، على خادم منفصل بمجلد تجريبي.
- اختُبرت معاينة ملف مولّد، وإضافة النطاق 1–3 ثانية: زادت المدة من 6 إلى 8 ثوانٍ، ثم أعاد التراجع المدة إلى 6.
- فُحص MCP باتصال حقيقي عبر stdio: اكتشاف الأدوات والإنشاء والاسم العربي والسلة والاسترجاع وأخطاء المشروع المفقود.
- صحح مسار السلة إلى `/api/projects/.trash` حتى يبقى المشروع القديم ذو معرّف `trash` قابلًا للفتح.
