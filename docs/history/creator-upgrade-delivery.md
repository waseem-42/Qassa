# تسليم تحسينات قَصّة — 2026-10-29

## المنفّذ

- رئيسية عربية متجاوبة مع البحث والترتيب والعرض الشبكي أو القائمة، صور مصغرة من وسائط المشاريع، وإجراءات مستقلة للفتح وإعادة التسمية والحذف.
- تغيير الاسم الظاهر بعملية قابلة للتراجع مع ثبات معرّف المجلد وروابط الوسائط.
- سلة مشاريع محفوظة على القرص، واسترجاع دون استبدال مشروع موجود. منع الحذف أثناء التحليل والتصدير والرفع والاستيراد، مع فحص المسارات والروابط الرمزية.
- معاينة المصدر واختيار البداية والنهاية ثم إضافة الجزء للمسار الرئيسي أو كبي-رول. الإضافة قابلة للتراجع.
- نقاط حفظ مسماة دائمة لحالة المشروع، واستعادة مع نسخة أمان تلقائية، وحماية من تعارض المراجعات والطلبات الجارية. نقاط الحفظ لا تنسخ ملفات الوسائط.
- فحص جاهزية التصدير، وتثبيت حالة المونتاج عند إرسال الطلب، وبيانات النسخة في المهام والنتيجة، وأسماء خرج مستقلة.
- أدوات MCP للإدارة ونقاط الحفظ والجاهزية وقراءة حالة المشروع؛ نفس API الذي تستخدمه الواجهة.

## التحقق

- 163 اختبارًا نجحت في 15 ملفًا بعد دمج الخادم والواجهة ونقاط الحفظ والتصدير.
- TypeScript وبناء واجهة الإنتاج نجحا.
- اختبار MCP فعلي عبر stdio نجح، بما فيه الاسم العربي، السلة والاسترجاع، نقاط الحفظ، رفض مراجعة قديمة، نسخة الأمان، وفحص عدم جاهزية مشروع فارغ.
- اختبار FFmpeg فعلي: أرسلت نسخة مدتها 4 ثوانٍ ثم تغيّر المشروع إلى ثانيتين. بقي الناتج 4.000 ثانية، H.264/AAC بدقة 1280×720، وبيانات النسخة تطابق الحالة المرسلة.
- اختبارات المتصفح استخدمت مشروعًا معزولًا وفيديو مولّدًا، وشملت إنشاء/إعادة تسمية/حذف/استعادة، معاينة جزء وإضافته والتراجع عنه، حفظ نقطة واستعادتها، وفحص وتصدير نسخة معاينة.
- مشاريع المستخدم الأصلية لم تستخدم لاختبارات التعديل.

## الدراسة وحدودها

استُخدم REA المحلي لتوثيق هوية ملف Resolve وبصمته. لم يصل الفحص إلى سلوك ميزات التطبيق؛ المقارنة الوظيفية تعتمد على الشيفرة المحلية ووثائق Blackmagic الرسمية. الأدلة والتوصيات في creator-workflow-research.md.

التصدير يثبت JSON المشروع؛ ملفات الوسائط والخطوط وLUT ورسوم HTML تبقى اعتماديات على القرص ويجب أن تبقى متاحة. فحص الجاهزية لا يثبت قابلية فك ترميز كل ملف أو سلامة كل اعتماد داخلي لرسوم HTML. سجل المهام الحالي في الذاكرة.

هذه دفعة تحسين مكتملة الوظائف الموضحة أعلاه؛ لا تمثل تكافؤًا مع كل إمكانات CapCut أو Resolve. اختيار اللقطات دلاليًا، التتبع وإعادة التأطير التلقائيان، واستعادة المهام بعد إعادة تشغيل الخادم تبقى أعمال منتج مستقلة.

أُصلح أيضًا فشل رندر بعض المقاطع الصامتة القصيرة، مع خمسة اختبارات رندر فعلية تتحقق من الصمت والمدة والموسيقى المضافة.
